# Етап 02А — локальне збереження даних

## Обсяг

- Відокремити доступ до класів, учнів і контактів інтерфейсом репозиторію.
- Зберігати єдиний версійований JSON-документ локально через платформне
  сховище `shared_preferences`.
- Записати синтетичні демодані лише тоді, коли ключ сховища ще не існує.
- Показувати українські стани завантаження та помилки без підміни пошкоджених
  або недоступних даних демоданими.
- Перевірити повторне відкриття, відсутність повторного засівання та помилки
  читання й запису.

## Поза обсягом

Форми редагування, імпорт, харчування, сервери, синхронізація, API ШІ,
шифрування, резервування та робота зі справжніми персональними даними.
