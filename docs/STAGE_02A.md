# Етап 02А — прототип локального сховища учнів

Мета: замінити вбудоване джерело демоданих на репозиторій із локальним прототипом,
не додаючи редагування, імпорт або харчування.

Готово: `StudentRepository` відокремлює UI від доступу до даних; реалізація на
`shared_preferences` зберігає один версійований JSON-документ із класами, учнями
та контактами. Перший запуск засіває лише відсутній ключ. Пошкоджений JSON,
невідома версія, помилка читання або запису не перезаписують наявне значення.

Обмеження: `shared_preferences` — лише прототип локального сховища. Він не надає
захисту персональних даних. До використання реальних відомостей потрібен окремий
етап із захистом доступу, шифруванням і резервним відновленням.
