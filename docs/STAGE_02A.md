# Етап 02А — локальне зберігання даних учнів

## Мета

Додати до наявного сценарію перегляду учнів замінний локальний шар даних без
розширення інтерфейсу функціями адміністрування.

## Реалізація

- UI працює через `StudentRepository` і не залежить від конкретного сховища.
- `SharedPreferencesStudentRepository` зберігає класи, учнів і контакти одним
  versioned JSON-документом зі `schemaVersion: 1`.
- Синтетичні демодані записуються лише тоді, коли ключ сховища відсутній.
  Збережений порожній стан, пошкоджений документ або несумісна версія не
  запускають повторне початкове заповнення.
- Недоступне сховище та непридатні локальні дані відображають окремий стан
  помилки з повторною спробою. Оригінальний документ при цьому не змінюється.
- Декодер перевіряє унікальність ID класів і учнів та належність кожного учня
  до наявного класу.

## Межі етапу

Ручне редагування й адміністрування належать етапу 02Б. Імпорт, харчування,
звіти, авторизація та захист справжніх персональних даних не реалізовані.
