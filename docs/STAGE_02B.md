# Етап 02Б — адміністрування класів і карток учнів

## Мета

Додати ручне керування синтетичними класами та картками учнів поверх локального
сховища етапу 02А, без імпорту, сервера або функцій наступних етапів.

## Реалізація

- Клас можна створити, перейменувати, архівувати та відновити. Стабільний ID не
  змінюється; клас з активними учнями архівувати не можна.
- Картка учня підтримує ПІБ, активний клас, спорт, кімнату, телефон і довільний
  список контактів дорослих. Учня можна створити, змінити, перевести, архівувати
  з датою та явно відновити.
- Активний список і пошук не містять архівних учнів. Для архіву є окрема кнопка.
- Правила та запис зосереджено в `StudentAdministration` і
  `StudentRepository`. UI приймає новий стан лише після успішного запису; при
  помилці показує українське повідомлення та дію повторення.
- JSON має `schemaVersion: 2`. Документ версії 1 явно читається, доповнюється
  станами архіву й одразу записується як v2. Пошкоджені та майбутні версії не
  перезаписуються.

## Перевірки та межі

Тести охоплюють міграцію, стабільність і унікальність ID, CRUD та переведення,
контакти, архів/відновлення, валідацію, повторне відкриття і відмову запису.
Мобільний сценарій перевіряється також із масштабом тексту 200%.

SharedPreferences залишається сховищем лише для синтетичного прототипу.
Імпорт, синхронізація, захист справжніх даних, журнали, харчування та звіти не
належать цьому етапу.
